M8MBC-586 brief list of jumpers, configuration switches and connectors:

# Configuration jumpers

J1001 and J1002 - CPU VCC_CORE source selection (CPU VRM or +3V3 rail):
- VCC_CORE from CPU VRM (Socket 7 CPUs):
J1001: 1-2, 3-4, 5-6, 7-8
J1002: leave all pins open
- VCC_CORE from +3V3 rail (Socket 5 CPUs):
J1001: leave all pins open
J1002: 1-2, 3-4, 5-6, 7-8

J201 - BUS_MUL - Bus multiplier selection (for Socket 7 CPUs):
1-2 - BF0
3-4 - BF1
5-6 - BF2
These signals are pulled down by default, so if the jumper is left open, the corresponding bit will be 0. See used CPU datasheet for the configuration of these bits for the desired multiplier.

JP201 - WB/WT# - Write-back / write-through cache selection
1-2 - HIGH, Write-back cache
2-3 - LOW, Write-through cache

JP901 - CMOS_CLR - CMOS clear jumper:
1-2 - Clear CMOS unconnected (normal operation)
2-3 - Clear CMOS connected (clear CMOS)

JP601 - ISA -5V source selection jumper:
1-2 - Use onboard -5V regulator
2-3 - Use -5V from PSU

J1107 - Front panel connector
