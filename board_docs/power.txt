M8MBC-586 power:

The M8MBC-586 features a standard 24-pin ATX power connector. It provides the necessary power rails for the board, including +3.3V, +5V, +12V, -12V, +5VSB and potentially -5V. 

+3V3:
The +3.3V rail is used to power:
- FPGAs VCCIO
- FPGAs VCCINT regulators
- SDRAM VCC
- CPU VCC_IO (and VCC_CORE if proper jumper is set / Socket 5 CPU is used)
- Clock buffers 
- PCI 3.3V rails.
- MAX3243 RS232 line driver 
- IDE SN74LVC245APW buffers
- Crystal oscillators
It is provided from the ATX PSU.

5V:
The +5V rail is used to power:
- CPU VRM
- PS/2 keyboard/mouse combo connector
- PCI 5V rails
- ISA 5V rails
- 74CBTD3384APW FET bus switches (PCI, ISA, other)
- ISA 74HCT541 buffers
- BIOS flash ROM
- Dallas RTC

12V:
None of the onboard components use the +12V rail directly. It is only used to provide 12V to PCI and ISA slots.

-12V:
Same as +12V, none of the onboard components use the -12V rail. Used only for PCI and ISA slots.


+3V3SB:
The +3V3SB rail is used to power the RP2040 system controller and other components that need to be powered even when the main power is off. It is also used to power the PCI bus standby power. It is provided by onboard AMS1117-ADJ voltage regulator (U603). The regulator takes +5VSB from the PSU.

-5V rail:
The -5V rail is only routed for the ISA bus. It is not used by any other components on the board. Because not all power supplies provide -5V, the board has a onboard -5V voltage regulator. The used IC is LM7905CT (U604). It uses -12V rail as input and provides -5V output. There is a jumper (JP601) to choose between using onboard -5V regulator or -5V from the PSU. 
JP601 jumper options:
1-2 - Use onboard -5V regulator
2-3 - Use -5V from PSU

FPGA VCC_INT rails (+1V2_F1-F3):
The FPGAs VCC_INT rails are powered by onboard voltage regulators. The used IC is LDL1117S-1.2 (U402, U502, U802). It takes +3.3V from the PSU and provides +1.2V output. The VCC_INT rails are used to power the internal logic of the FPGAs.
